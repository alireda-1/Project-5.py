# Birth Year Calculator

A simple and optimized **Python** script that calculates the user's birth year based on their current age.

## Features
- **Code Optimization:** Improved from a 5-line commented approach to a clean, efficient 2-line execution.
- **Smart F-Strings:** Utilizes modern Python f-strings to perform dynamic calculation and text formatting inside the print statement.
- **Instant Calculation:** Subtracts the user's age from the year 2026 to output their exact birth year immediately.

## Technologies Used
- Python 3
